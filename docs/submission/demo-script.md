# Saath — 3-Minute Demo Script

Total: ~180 seconds. Narrator speaks; screen shows the app at
http://127.0.0.1:8091/web/ logged in as `demostudio`.

## 0:00–0:20 — The promise (Home + Jizo)
> "Meet Saath — one companion for everything in daily life. Say hello
> to Jizo."
- Show Home: Jizo blob floats, greeting visible.
- Say "Hi Jizo" (or click mic): "Good evening! What shall we do today?"

## 0:20–0:50 — Real understanding → delegation (Chat)
> "I tell Saath what I need in plain words. It understands, plans,
> and its agents do the work — with my approval for anything real."
- Type: "Plan a trip to Jaipur for 3 relaxed days with good hotels."
- Show the plan + delegated tasks; open Tasks to show parent/child
  rows and audit events (proof it is real, not a chat bubble).

## 0:50–1:15 — Demo bookings, honestly labeled (Bookings)
> "Saath walks through complete bookings — cabs, appointments, party
> invites — every one clearly marked DEMO, nothing faked as real."
- Book a cab; point at the DEMO-XXXX reference.
- Show the approval prompt; approve; show the stored booking.

## 1:15–1:45 — Visual Tutor video, generated locally (Learn → Videos)
> "And Saath teaches. This kettle tutorial was planned by Muse,
> illustrated by Muse, animated and narrated on this device."
- Play `How to use an electric kettle safely` (already COMPLETED).
- Point at the "Muse-powered illustrated video" label; ask a
  follow-up: "Explain step two again."

## 1:45–2:15 — Real integrations (Calendar, Gmail, Maps)
> "Where it touches the real world, it touches it for real."
- Calendar: show today's events (live Google data).
- Nearby: search "dentist" — show LIVE badge, then a route with
  distance and time.
- Gmail: show the connected status (send-only, honest scope).

## 2:15–2:40 — Hindi + voice for everyone (Settings)
> "Saath speaks to everyone: Hindi lessons, Hindi replies, and
> hands-free voice — no button-tapping for elders or
> visually-impaired users."
- Flip "Saath replies in" to Hindi; ask one question; show Hindi reply.
- Show the Hindi lesson option in Videos.

## 2:40–3:00 — Trust close (Approvals + Developer)
> "And Saath never pretends: approvals gate every real action,
> failures are reported, and 218 automated tests guard it all."
- Flash Approvals screen + test count. End on Jizo celebrating.

## Recording notes
- Start the server first (see checklist). Keep Chrome at 1280×800.
- Pre-open tabs: Home, Chat, Bookings, Videos, Calendar, Nearby.
- If live Muse quota is exhausted mid-demo, chat falls back to the
  honest offline stub — say so on camera; it is a feature, not a bug.
